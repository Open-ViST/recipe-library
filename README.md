# OpenViST Recipe Library

Only publicly published recipes are included. Each version retains its exact code SHA-256, usage, sources, limits and recorded validation scope. No recipe is executed during export.

## Organization

`recipes/<language>/<slug>/v<version>/` contains the code, README, metadata and license. `catalogue.json` is the machine-readable index.

## License

Scripts use MIT, matching the license published by OpenViST. Adapted examples retain their upstream copyright notices beside the code and in THIRD_PARTY_NOTICES.md.

## Before running

Read each recipe's requirements, limits and source links. Some API examples need your own credentials and can incur provider charges when you run them. Never commit credentials. A recorded test scope is not a guarantee for arbitrary inputs or environments.

## Refresh from published OpenViST recipes

Run `python3 tools/export_library.py --output .` from this repository, inspect the diff, and commit the intended additions. Existing published versions are preserved; differing code or documentation requires explicit review.
